# AutoScribe v1.5.0

AutoScribe یک برنامهٔ دسکتاپ است که **Windscribe CLI** رسمی را به‌جای شما اجرا می‌کند. این برنامه
سرورها، پروتکل‌ها و پورت‌هایی را که انتخاب کرده‌اید یکی‌یکی امتحان می‌کند، به هر کدام وصل می‌شود، پینگ،
درصد از دست رفتن بسته‌ها (packet loss) و در صورت انتخاب، باز شدن واقعی وب (HTTP/HTTPS) را از داخل تونل اندازه می‌گیرد و بهترین ترکیب‌ها را رتبه‌بندی می‌کند.

## قابلیت‌های جدید در نسخهٔ 1.5.0

- **هدف‌گیری دقیق نودها و گزینهٔ «یک سرور از هر شهر»** – رفع مشکل تکرار تست شهرها با ارسال نام دقیق نود به `windscribe-cli` و امکان تست تنها یک سرور از هر شهر چندسروره.
- **فیلتر «فقط سرورهای رایگان»** – رد کردن خودکار سرورهای مخصوص حساب Pro و نمایش برچسب `[رایگان]` در پنجرهٔ انتخاب مکان‌ها.
- **گزینهٔ «حفظ فایروال Windscribe»** – جلوگیری از اجرای خودکار `windscribe-cli firewall off` در زمان قطع اتصال بین تست‌ها.
- **بررسی اتصال وب (HTTP/Web Check)** – تست واقعی باز شدن ترافیک وب از داخل تونل (علاوه بر پینگ ICMP) و ثبت تأخیر وب در جدول نتایج، بهترین مسیرها، دیتابیس و خروجی CSV.
- **تب «عیب‌یاب لاگ» (Diagnostics)** – تحلیل‌گر داخلی برای فایل باینری `config/log.bin`، لاگ سرویس WireGuard و تنظیمات ضدسانسور `config.ovpn` جهت تشخیص دقیق تایم‌اوت‌های Handshake و مسدودیت‌های شبکه.
- **بهبود مفسر Ping** – پشتیبانی از خروجی‌های IPv6 و نسخه‌های محلی ویندوز/لینوکس حتی بدون فیلد `TTL`.

## پیش‌نیازها و اجرا

- **ویندوز ۱۰ یا ۱۱**
- **پایتون 3.9 یا جدیدتر** همراه با Tkinter و بستهٔ `customtkinter` (`pip install -r requirements.txt`)
- **برنامهٔ دسکتاپ Windscribe** که وارد حساب کاربری شده باشید (`C:\Program Files\Windscribe\windscribe-cli.exe`)

</div>

```bash
pip install -r requirements.txt
python main.py
```

## ساخت فایل اجرایی (.exe)

می‌توانید از فایل `AutoScribe.exe` موجود در بستهٔ اجرایی استفاده کنید یا با اجرای `build_exe.bat` (یا دستور زیر) یک تک‌فایل مستقل PyInstaller بسازید:

</div>

```bash
pip install pyinstaller
pyinstaller --noconsole --onefile --name AutoScribe --collect-data customtkinter main.py
```
