AutoScribe — настольное приложение, которое управляет официальным **Windscribe CLI**. В версии **1.5.0** добавлены:

- **Точный выбор узлов и опция «Один сервер на город»** — устранение повторных тестов одного и того же города.
- **Фильтр «Только бесплатные серверы»** — пропуск Pro-локаций и метка `[FREE]` в списке локаций.
- **Опция «Не выключать файрвол»** — сохранение состояния файрвола Windscribe между тестами.
- **Проверка HTTP/веб-трафика через туннель** — измерение реального HTTP-отклика наряду с ICMP-пингом.
- **Вкладка «Диагностика» (Diagnostics)** — встроенный анализатор бинарного журнала `config/log.bin`, `wireguard_service.log` и `config.ovpn`.
- **Улучшенный парсер Ping** — поддержка IPv4/IPv6 и локализованных выводов `ping`.

## Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```
